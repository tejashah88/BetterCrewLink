## READ ME FIRST

This is a modded version of BetterCrewLink that adds voice volume normalization: it softens loud voices (to protect against mic spammers) and boosts quiet voices (for the shy people in the back). If you just want the regular version of BetterCrewLink, please go here: https://github.com/OhMyGuus/BetterCrewLink. Credits go to OhMyGuus for the original project.

To use it, go to settings (:gear: icon), scroll down to "Player Volume Tweaks" and enable it. The slider adjusts the maximum incoming volume from the other players in decibels (dB). Refer to the chart below for a quick conversion chart.

| Decibels (dB) | Volume (%) |
| ------------: | ---------: |
|             0 |     100.0% |
|            -6 |      50.0% |
|           -12 |      25.0% |
|           -18 |      12.5% |
|           -24 |       6.3% |
|           -30 |       3.2% |
|           -36 |       1.6% |
|           -42 |       0.8% |
|           -48 |       0.4% |
|           -54 |       0.2% |
|           -60 |       0.1% |
